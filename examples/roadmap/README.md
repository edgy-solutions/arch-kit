# Roadmap example (Yarrow)

A standalone project with `files.roadmap`. Every name in it is invented. The export snapshot is added when render_html
wires the roadmap page in; until then `expected/roadmap.html` is the output of `roadmap.render` and `roadmap.nav`,
checked by `test_example_roadmap.py`. `registers.roadmap` names a note that does not exist, which is allowed.
